Design and implement a polished responsive single-page web application named **CityPulse**, a workspace for discovering and organizing neighborhood events.

Work only in `index.html`, `styles.css`, and `app.js`. Do not modify tests or configuration. Use plain HTML, CSS, and JavaScript with no external packages, fonts, images, CDNs, or network requests. Everything must work by opening `index.html` locally.

The product must include:

- A clear brand/header area and primary navigation.
- Search plus category/date filtering with visible active states.
- A week or date-oriented overview that makes upcoming activity easy to scan.
- At least six realistic seeded events with useful metadata such as date, time, location, category, attendance, or availability.
- A focused event detail experience when a user selects an event.
- A create-event dialog with labeled fields, cancel/submit actions, keyboard dismissal, and visible success feedback.
- A save/bookmark interaction whose state remains visible.
- Meaningful empty-filter feedback and a way to reset filters.
- A genuinely adapted mobile layout around 390px wide, not merely a squeezed desktop page.
- Semantic landmarks, visible keyboard focus, readable contrast, reduced-motion handling, and sensible ARIA where native semantics are insufficient.

Choose the visual direction yourself. Aim for a distinctive, credible product rather than a generic component template. Avoid decorative complexity that harms scanning or interaction. Ensure it works at both 1440×1000 and 390×844.

Run `node --test` and `node --check app.js` before finishing.
